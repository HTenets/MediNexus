🚀 核心功能

不止是聊天 — 完整的 AI 问诊体验

🩺

AI 智能问诊

输入症状，AI 自动分诊、诊断、出方案。支持 WebSocket 流式对话，实时反馈。

📚

三路 RAG 知识库

临床病例 + 医学理论 + 前沿论文，Qdrant 向量检索 + BM25 降级，确保回答有据可查。

🛡️

独立审核机制

Review Agent 独立验证诊断结果，8 维审查（药物交互/禁忌症/剂量/过敏/证据等级等）。

🧠

分层记忆系统

工作记忆（Redis）+ 情景记忆 + 语义记忆，跨会话追踪患者健康状况。

⚠️

紧急检测 + 免责

50+ 关键词 + 7 条正则检测紧急信号，自动触发急救指引。所有回答附加医疗免责声明。

🔌

4 大专科 Skill

内置内科、皮肤科、耳鼻喉科、心理科 Skill。插件架构支持社区扩展（v0.3.0+）。
