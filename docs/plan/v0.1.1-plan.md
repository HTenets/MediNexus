# MediNexus v0.1.1 开发路线图 — 去伪存真

> 版本主题：让宣称的能力真实运转，让展示的数据真实可信。
> 基线：v0.1.0（2026-08-30 完成前后端实现状态审计，见文末附录）

---

## 一、版本定位

v0.1.0 的核心问诊链路（登录 → 多智能体问诊 → 复核 → 总结）是真实可用的，
但存在三类系统性问题：

1. **卖点功能未接线** — Mem0 分层记忆、RAG 检索、知识图谱均为"代码存在但运行时不参与"；
2. **关键路径根本跑不通** — 密码哈希依赖组合不可用、`/auth/refresh` 被中间件拦截，认证全链路崩溃；
3. **前端假数据** — 数字孪生/健康档案/设置等页面靠硬编码数据撑起，`/consultation/analysis` 为死链。

v0.1.1 聚焦**完善与去伪**，不引入新视觉体系。
前端视觉重设计（方案一「Bioluminescent Clinical」，`web-design/redesign-plan-a/`）单独立为 **v0.2.0** 里程碑。

## 二、现状调研：已实现 vs 假数据

> 审计方式：代码走查 + `pytest` 实证 + `tsc --noEmit` / `npm run build`，非凭文档推断。

### 2.1 后端

| 模块 | 判定 | 依据 |
|------|------|------|
| 四 Agent 问诊链路 | ✅ 真实 | LLM 模式 + 规则降级双通道，集成测试覆盖 |
| PII 脱敏 + 紧急检测护栏 | ✅ 真实 | `BaseAgent.on_pre_process` 中强制执行 |
| LLM 三提供商 | ✅ 真实 | Ollama / OpenAI / Anthropic，含真流式 `chat_stream` |
| JWT 签发 | ✅ 真实 | — |
| **密码哈希（bcrypt）** | ❌ **完全不可用** | passlib 1.7.4 读 `bcrypt.__about__`（bcrypt 4.1 已移除），自探测失败后不再截断 72 字节，bcrypt 5.0 随即抛 `ValueError`。**任何一次 hash/verify 都失败**，与密码长度无关 |
| **`/auth/refresh`** | ❌ **不可达** | 未在 `PUBLIC_PATHS` 中，被 `auth_middleware` 401 拦截。而刷新令牌的调用场景恰恰是 access token 已过期 —— 用户一旦过期即永久登出 |
| 专科 Skill 系统 | ✅ 真实 | 内/皮肤/耳鼻喉/心理，按症状与科室自动匹配 |
| 患者 / 病历 / 会话持久化 | ✅ 真实（P0 已建） | PostgreSQL + 手写初始迁移；无库时内存降级，所有权语义一致 |
| **分层记忆** | 🚧 **全桩** | `MemoryManager.retrieve()` 恒返回 `""`，四个类只有 `pass`/`[]`，且全项目零实例化 |
| **RAG** | 🚧 **零实例化** | `RAGQuery` 仅被 `graph_rag.py`（本身未被调用）引用；`ReviewAgent` 实际走 `_seed_search()` 关键词查表 |
| LangGraph 编排 | 🚧 装饰性 | 仅 `graph.py` import `langgraph`，该模块无任何调用方 |
| **流式输出** | ❌ **假** | `main.py` 把渲染好的文本按 2 字切片 + `sleep(0.012)` 模拟打字 |
| Celery | 🚧 未接线 | 任务已定义，无调用方 |
| CoordinatorAgent | 🚧 不可达 | 已注册，但没有任何路径把 `current_agent` 置为 `coordinator` |
| `app/api/mock_data.py` | 🗑 死代码 | 未注册进 router |
| `app/core/redis.py` | 🗑 死代码 + 有 bug | 无引用；`redis_url` 为空时构造即失败 |

### 7.2 本轮修复与实现

**P0.5 密码哈希（阻塞项）**
- `app/core/password.py` 改为直接调用 `bcrypt`：`hashpw` / `checkpw` / `gensalt(rounds=12)`，
  按**字节**截断 72 位（中文等多字节字符会被正确裁切）
- `verify_password` 对畸形哈希返回 `False` 而非抛异常
- 依赖：`passlib[bcrypt]` → `bcrypt>=4.1`（`requirements.txt` 与 `pyproject.toml`）
- 效果：8 个认证测试由红转绿

**P0.6 刷新令牌可达性**
- `PUBLIC_PATHS` 增加 `/api/v1/auth/refresh` 与 `/api/v1/auth/logout`
- 补充注释说明：刷新端点的调用场景正是 access token 已过期，要求其带 access token 等于永久登出

**P1.3 分层记忆（新增 `memory/_redis.py`，重写三个 tier 与 manager）**
- `WorkingMemory`：Redis / 进程内双写，会话作用域 API（agent、context、exists、delete），`SESSION_PREFIX = "session:"`
- `EpisodicMemory`：`consultations` 表 + 进程内列表，`store` / `recall` / `format_recall`
- `SemanticMemory`：`patients` 表 + 进程内字典，过敏史 / 既往史 / `format_profile`
- `MemoryManager`：三层门面，`retrieve()` 组合档案与既往记录为 LLM 上下文块
- 接入：`SupervisorAgent` 在 `run_agent` 前注入 `patient_memory`，在会话终态归档 Episode，同步 working memory
- `DoctorAgent` 把记忆并入 `patient_history`；`ReviewAgent` 把记忆并入复核提示（用药禁忌检查依赖过敏史）
- 全部为 best-effort：记忆异常只记日志，不阻断问诊（已有测试覆盖）

**P1.4 RAG 接线（新增 `knowledge/factory.py`、`app/core/rag.py`、`app/api/knowledge.py`）**
- `create_rag_query()`：BM25（内置知识库，始终可用）+ 可选 Qdrant 向量路由 + 知识图谱
- 嵌入器：Ollama `/api/embeddings` 与 OpenAI 兼容 `/embeddings`；不可用时走 BM25，不做哈希假嵌入
- `RAGQuery` 新增 `force_fallback`，让"无向量库时走 BM25"成为显式意图而非静默降级
- 注入路径：`app.main` 构建 → `set_rag_query()` → `supervisor.rag_query` → `ReviewAgent.rag_query`
- 新增 `GET /api/v1/knowledge/search`（按三源分桶返回）与 `GET /api/v1/knowledge/health`（公开）
- 精度：BM25 增加相对分数阈值（`min_score_ratio=0.2`），抑制中文二元分词带来的低质量匹配

**P1.1 真流式（新增 `orchestration/narrative.py`）**
